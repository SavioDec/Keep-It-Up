# Keep It Up (Aula 01)

Este é um projeto Android desenvolvido para estudo e acompanhamento de leitura de livros (Media Tracker). Ele demonstra a criação de listas dinâmicas com `RecyclerView`, navegação entre telas via `Intent` e estilização baseada no Material Design 3.

## Funcionalidades
- **Lista de Livros**: Exibe uma listagem de livros na tela inicial.
- **Detalhes do Livro**: Ao clicar em um livro, o aplicativo redireciona para uma tela detalhada contendo sinopse, capa, progresso de leitura e outras informações.
- **Progresso de Leitura**: Sistema interativo que permite incrementar ou decrementar o progresso atual das páginas lidas do livro.
- **UI Moderna**: Interface utilizando Material 3 (`Theme.Material3.Dark`), botões flutuantes (`FloatingActionButton`) e emblemas (`Badges`).

## Estrutura Técnica
- **Linguagem**: Kotlin
- **Interface**: XML Views com `ViewBinding`
- **Layouts**: `LinearLayout`, `FrameLayout`, `ScrollView`
- **Componentes**: `RecyclerView`, `FloatingActionButton`, `LinearProgressIndicator`
